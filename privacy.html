Política de privacidad — Bot Classroom

Última actualización: 27 de septiembre de 2026

Qué datos se usan

Con la autorización del usuario, la aplicación lee mediante la API oficial de Google Classroom, con permisos de solo lectura:

  • La lista de cursos activos (nombre del curso).
  • Las tareas publicadas en esos cursos: título, descripción, tipo, fecha de entrega, puntaje, nombres del material adjunto y enlace a la tarea.

La aplicación no lee calificaciones, entregas, correos, contactos ni ningún otro dato de la cuenta de Google.

Para qué se usan

Únicamente para detectar tareas nuevas o modificadas y enviar un aviso con esa información a un canal de Discord elegido por el propio usuario.

Dónde se guardan

Los datos de las tareas y el token de acceso se guardan solo en el servidor privado del dueño del bot. No se venden, no se comparten con terceros y no se usan para publicidad. La información enviada a Discord queda sujeta a la política de privacidad de Discord.

Uso de datos de las API de Google

El uso y la transferencia de la información recibida de las API de Google cumplen con la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El usuario puede revocar el acceso en cualquier momento desde myaccount.google.com/permissions. Al hacerlo, la aplicación deja de poder leer Classroom.

Contacto
